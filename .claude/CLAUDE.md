- Sve izmene commituj i pushuj direktno na granu `main` (`git push origin main`).
- U commit porukama NIKADA ne dodaj `Co-Authored-By: Claude`, `Claude-Session` niti bilo kakvu drugu Claude atribuciju.
- Autor i committer svakog commita mora biti `vladix101 <seminarski1001@gmail.com>`, nikada Claude. Pre commita podesi: `git config user.name "vladix101"` i `git config user.email "seminarski1001@gmail.com"`.
